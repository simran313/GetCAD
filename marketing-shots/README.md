# Marketing shots

Made by `tests/marketing-shots` on the throwaway e2e stack (never production).
The demo client is "[Your Jewelry Co.]", client code AB1. Its orders were created through the app's real screens.
Every screen comes at two widths: `_390` (phone) and `_1440` (desk).

| File | What it shows |
| --- | --- |
| `client_home` | Home: the design ready to review, messages, recent orders, the 5h 42m first-look countdown |
| `client_orders_new` | New order |
| `client_brief` / `client_brief_pins` | Brief form; the reference photo with 2 numbered pins |
| `client_order` | AB1-RN-S-07 delivered: stepper, tiles (revisions 0 of 2 used), Files ready, 3D preview link card, spec guarantee card |
| `client_order_in_progress` | AB1-RN-S-09 in design, first look in about 5h 42m |
| `client_review` | AB1-RN-S-08 ready for you: approve or ask for changes |
| `client_pay` | AB1-RN-S-10 quoted at $35 |
| `client_files` | Files, by order |
| `client_chat` | Chat: marked-up photo, team reply, voice note |
| `public_preview` | The branded 3D preview link (/p/…) with the placeholder logo |
| `designer_final_review` | Designer's final review: references with pins, 3D model, QC checklist |
| `marketing_home` / `marketing_home_hero` | Website home, full page and first screen |
| `certificate_AB1-RN-S-07.pdf`, `summary_sheet_…`, `weight_sheet_…` | The delivered order's documents |
| `technical_image_AB1-RN-S-07.png` | The technical image, with gold weight and diamond details joined underneath |
| `pillar-mark_*` | The mark: black and white SVG, 1024 px PNG (transparent, and on white) |

`CHECK.md` holds the scan of every screen and document for the e2e test names. It is clean.
The ring model, photos, render, technical drawing and logo are made in code: nothing licensed or private.
On the homepage shots, the sample card's code was swapped in the picture only: MJ1-RN-C-10 now reads AB1-RN-S-07.
